## 📋 操作时间线（成功全程）

### 阶段 1：重装系统（治本）
- 原定制镜像 `Sealed: Broken` 是万恶之源 → OCLP 报"根目录不纯净"死锁
- **抹盘重装** Sonoma 14.8.9：
  - 抹盘时系统盘 EFI 分区(disk0s1)幸存了（只删了 APFS 容器）
  - 用工具盘(IMACOS_TOP)引导进 Recovery → 系统盘空闲 → 随便抹
  - 下载 8-13GB，5-9MB/s，重装成功

### 阶段 2：EFI 折腾（弯路与回归）
- 系统盘 EFI 残留着重装前改的 N卡版（MD5 23487...）
- **试官方N卡版 EFI（imacos.top 版）** → 引导不行 ❌
- **改回自己之前改的版本**（ngfxgl/ngfxcompat/nvda_drv_vrl + csr 0x0FFF + Delete 完整）→ ✅ 成功

三个 EFI 版本对比（全部已备份）：
| EFI | MD5 | boot-args | 状态 |
|-----|-----|-----------|------|
| 正常版 | 77854... | keepsyms=1 -v | 备用 |
| **自改N卡版** | 23487... | ngfxgl=1 ngfxcompat=1 nvda_drv_vrl=1 amfi_... | ✅ **最终使用** |
| 官方N卡版 | 203bb... | amfi_... -no-compat-check | ❌ 引导失败 |

### 阶段 3：网络问题（三大解法）
1. **OCLP-Mod 内置国内加速**（作者 laobamac 是中国人）：
   ```python
   # 源码证据 gui_update.py
   cnurl = url.replace("https://github.com/", "https://download.simplehac.cn/https://github.com/")
   # defaults.py: 中国网络自动 use_simplehacapi = True
   # KDK/Metallib/API 全部走 simplehac.cn 国内节点
   ```
2. **Clash 代理兜底**（本地 Clash Verge + mihomo 内核）：
   - 开启 **Allow LAN**（监听 *:7897）
   - macOS 三层配置：
     ```
     系统代理(Web):   192.168.31.204:7897 ✅
     系统代理(Secure): 192.168.31.204:7897 ✅
     环境变量: http_proxy/https_proxy → 192.168.31.204:7897 ✅
     ```
   - 验证：macOS 走代理访问 GitHub = 200 ✅
3. **KDK 手动方案**（备用）：Apple 开发者站国内可直连

### 阶段 4：打补丁成功 ✅
- OCLP-Mod 3.1.9 → Start Root Patching → 成功！
- 证据：`com.nvidia.NVDAStartupWeb (10.3.3)` 已加载

## 🧠 核心经验

```
1. 定制镜像的 Sealed: Broken = 无解，重装才是正路
2. 抹盘只删 APFS 容器，EFI 分区(disk0s1)会幸存——记得检查
3. EFI 备份要三份: 正常版/自改N卡版/官方N卡版
4. 官方N卡版不一定能用，自己验证过的配置最可靠
5. OCLP-Mod 作者是中国人，内置 simplehac 国内加速，不用翻墙
6. Clash 要开 Allow LAN，且 OCLP 认环境变量(launchctl setenv)不认系统代理
7. 判断驱动是否加载看 kextstat，别信 system_profiler 的 "No Kext Loaded"
```
