# 黑苹果 P400 卡顿排查与优化全记录

> 日期: 2026-09-07 | 环境: PVE 8 + macOS Sonoma 14.8.9 VM 102
> 显卡: NVIDIA Quadro P400 (GP107/Pascal) 直通 + WebDriver + OCLP-Mod 3.1.9
> 问题: 系统卡爆, 鼠标一动就卡, 时好时坏

---

## 一、症状与排查过程

### 1.1 症状
- 系统整体卡顿, 鼠标移动时 WindowServer CPU 飙到 109%
- 时好时坏: "关显示器再开" 一段时间会突然变流畅
- 静态桌面也卡, load average 高达 32-100

### 1.2 关键诊断数据
| 状态 | WindowServer | load | 说明 |
|------|-------------|------|------|
| 卡 | 109% CPU | 32-100 | 软件渲染或后台服务爆吃 CPU |
| 不卡 | 0.1-3% | ~2 | 健康状态 |

### 1.3 排除的伪因 (重要教训)
| 怀疑对象 | 结论 |
|---------|------|
| VBIOS 无 GOP | ❌ 假象! rom-parser 验证 P400 一直有 EFI 段 (type 3) |
| Metal 不支持 | ⚠️ 真实但非主因 — WebDriver 在 Sonoma 无 Metal 是已知限制 |
| 镜像模式 | ⚠️ 部分是主因之一, 已通过屏蔽虚拟显卡根治 |
| CPU 锁频 | ❌ 假象, 实际是后台服务占满 CPU |

---

## 二、真正原因 (两个)

### 2.1 后台服务疯狂吃 CPU (主因)
```
triald  92%  ← 试用期检查服务
remindd 69%  ← 提醒事项后台
CarbonComponentScannerXPC 46% ← 音频组件首次扫描
tccd   58%  ← 权限服务 (重启Dock时瞬时)
```
开机后这些服务疯狂工作 → load 100+ → 系统假死。

**"关显示器再开就流畅"是错觉** — 其实是这些后台任务刚好跑完了。

### 2.2 VMware 虚拟显卡参与渲染 (次因)
- vga: vmware 的虚拟显卡 (7MB, 15ad:0405) 被 macOS 识别为显示器
- 双显示器时镜像模式 → WindowServer 同时渲染两份 1080p
- 虚拟卡无硬件加速 → 拖慢整体渲染

---

## 三、解决方案

### 3.1 屏蔽 VMware 虚拟显卡 (OpenCore DeviceProperties)
在 `EFI/OC/config.plist` 的 DeviceProperties > Add 注入:

```xml
<key>PciRoot(0x0)/Pci(0x8,0x0)</key>
<dict>
    <key>class-code</key>
    <data>AP///w==</data>  <!-- 二进制 00ffffff = 无效设备类 -->
</dict>
```

**⚠️ 踩坑记录:**
- PlistBuddy 的 `data` 参数写入的是 ASCII 文本, 不是二进制!
  - 错误: `data ff000000` → 存入 "ff000000" 字符串 (8字节)
  - 正确: python3 `struct.pack("<I", 0x00FFFFFF)` → 4字节二进制
- macOS 上的 python3 缺 Command Line Tools 用不了
- **正确做法: 在 PVE 上挂载 EFI, 用 PVE 的 python3 写二进制**

验证生效: `system_profiler SPDisplaysDataType` 显示虚拟卡 `No Kext Loaded`, 镜像选项消失。

### 3.2 关闭后台服务
```bash
sudo launchctl unload /System/Library/LaunchDaemons/com.apple.triald.system.plist
sudo launchctl unload /System/Library/LaunchDaemons/com.apple.remindd.plist
```
(remindd 实际在 /System/Library/LaunchAgents/com.apple.remindd.plist)

### 3.3 关闭系统特效 (无硬件加速卡的标配)
```bash
# 系统设置 → 辅助功能 → 显示
defaults write com.apple.universalaccess reduceTransparency -bool true  # 减少透明度
defaults write com.apple.universalaccess reduceMotion -bool true        # 减弱动态

# Dock 特效
defaults write com.apple.dock magnification -bool false
defaults write com.apple.dock mineffect -string "scale"
defaults write com.apple.dock launchanim -bool false
killall Dock

# 全局动画
defaults write NSGlobalDomain NSAutomaticWindowAnimationsEnabled -bool false
defaults write com.apple.finder DisableAllAnimations -bool true

# Spotlight 索引 (可选)
sudo mdutil -i off /

# iCloud 同步 (可选)
sudo launchctl unload /System/Library/LaunchAgents/com.apple.CloudDocsDaemon.plist
```

## 六、教训总结

1. **"时好时坏"的卡顿先查后台进程, 别急着动显卡配置** — `ps aux | sort -rn` 是第一步
2. **PlistBuddy 写二进制 data 是坑** — 永远用 python3 plistlib
3. **改 EFI 前必备份** — 备份名: config.plist.bak-novga / bak-novga2
4. **"黑屏/卡顿"的临时恢复手段记录**: 显示器关开, 杀后台进程, 重启 WindowServer
5. **P400 + Sonoma 的物理限制**: 无 Metal 加速, 特效必须全关才流畅
