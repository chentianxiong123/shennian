# USB 设备共享协议折腾记录

> 设备：Xiaomi R3 (Mi Router 3) / PandoraBox 19.01 / MT7620 MIPS / 128MB RAM
> U 盘：Intel Optane 傲腾 USB / 13.4GB (ext4)
> 网络：Wi-Fi WISP 中继 + 100Mbps LAN

---

## 一、试过的协议总览

| 协议 | 服务器 | Windows 客户端 | 服务器开销 | 安装难度 |
|------|--------|---------------|-----------|---------|
| **Samba (SMB)** | PandoraBox 自带 | 内置，零安装 | ~11MB 进程 | 自带 |
| **NFS v3 (unfs3)** | opkg 安装 | 需第三方（家庭版无内置） | ~8MB 进程 | 简单 |
| **FTP (vsftpd)** | opkg 安装 | 不能挂盘符 | 轻 | 简单 |
| **WebDAV** | 需装 lighttpd | 能映射但不稳 | 轻 | 复杂 |
| **iSCSI (tgt)** | opkg 安装 | **内置，家庭版也有** | ~1MB + 133KB | 简单 |
| **SFTP (sshfs)** | Dropbear+openssh-sftp | SSHFS-Win (开源) | 轻 | 中等 |

## 二、实测性能对比

### 顺序读写 (网络 Samba/iSCSI)

| 测试项 | Samba | iSCSI (tgt) | 提升 |
|--------|-------|-------------|------|
| 顺序写入 (50MB) | **9.7 MB/s** | **14.6 MB/s** | **+50%** |
| 顺序读取 (50MB) | 24.2 MB/s | ~308 MB/s* | 缓存加速 |

### 4K 随机读写 (碎文件场景)

| 测试项 | Samba | iSCSI (tgt) | 提升 |
|--------|-------|-------------|------|
| 4K随机写入 | 571 IOPS (2.23MB/s) | 79 IOPS (0.31MB/s) | ❌ 数据异常 |
| 4K随机读取 | 420 IOPS (1.64MB/s) | **658 IOPS (2.57MB/s)** | **+57%** |

### 路由器本地 dd 测速 (不经过网络)

| 测试项 | 速度 |
|--------|------|
| 顺序写入 (U盘) | 25.3 MB/s |
| 顺序读取 (U盘) | 31.1 MB/s |
| 4K 随机写入 | 20.0 MB/s (5000 IOPS) |
| 4K 随机读取 | **40.0 MB/s (10000 IOPS)** ← 傲腾真实力 |

## 三、各协议优缺点

### 1. Samba (SMB)

- **优点：** Windows 原生支持，零安装，全屋共享，手机/电视/游戏机都能用
- **缺点：** MIPS CPU 负担重，4K 碎文件慢（420 IOPS），协议开销大
- **结论：** ✅ 最通用，全屋共享唯一可行方案

### 2. NFS v3 (unfs3)

- **优点：** 服务器轻量（~8MB），4K 性能略好于 Samba
- **缺点：** Windows 家庭版无内置 NFS 客户端，第三方都需要注册/折腾
- **结论：** ❌ Windows 家庭版劝退

### 3. FTP (vsftpd)

- **优点：** 极轻量
- **缺点：** Windows 不能挂盘符，不适合日常使用
- **结论：** ❌ 不适合此场景

### 4. WebDAV

- **优点：** Windows 可映射
- **缺点：** 服务器没装，HTTP 协议碎文件更差
- **结论：** ❌ 不如 Samba

### 5. iSCSI (tgt) ⭐ 推荐

- **优点：**
  - 块级协议，性能最好（658 IOPS 4K随机读）
  - Windows 所有版本内置 iSCSI 发起程序
  - 服务器极轻量（tgt 133KB + 内核模块）
  - 挂载后是本地磁盘，体验最好
- **缺点：**
  - 一次只能一台电脑挂载（不能全屋共享）
  - 需要格式化为 NTFS
- **结论：** ✅ **单机最佳选择**

### 6. SFTP (SSHFS)

- **优点：** 开源，基于 SSH
- **缺点：** SSH 加密开销大，4K 比 Samba 还慢
- **结论：** ❌ 慢

## 四、最终部署方案

```
┌─────────────────────────────────┐
│             路由器               │
│  Xiaomi R3 / PandoraBox 19.01   │
│                                 │
│  ┌──── Samba (SMB) ────┐        │
│  │  全屋设备共享        │        │
│  │  \\192.168.1.1\sda1 │        │
│  └─────────────────────┘        │
│                                 │
│  ┌─── iSCSI (tgt) ─────┐       │
│  │  单机高性能          │       │
│  │  iqn.2024-07.local   │       │
│  │  :cache:chrome       │       │
│  └─────────────────────┘        │
│                                 │
│       Intel Optane U盘 (ext4)    │
│       13.4GB                    │
└─────────────────────────────────┘
```

- **多设备共享文件 → Samba** （Windows 直接 \\192.168.1.1)
- **单机需要高性能 → iSCSI** （Windows iSCSI 发起程序连）
- **U盘是傲腾** → 读写寿命长，4K 随机读 10000 IOPS，但被路由器百兆口 + MIPS CPU 限制

---

## 五、关键发现

1. **瓶颈在路由器，不在 U 盘**：傲腾在路由器本地测 4K 读 40MB/s，经过 Samba 只剩 1.6MB/s，差了 25 倍
2. **iSCSI 比 Samba 快**：块级协议，CPU 开销更小，顺序写 +50%，4K 读 +57%
3. **拉网线能到百兆上限 (~11MB/s)**：现在走 Wi-Fi WISP 中继已经比百兆口快了（顺序读 24MB/s）
4. **这个路由器极限就在这了**：580MHz MIPS + 128MB RAM + 百兆口，想更快只能换设备
