# 失败记录 - 2026-07-19

## 环境
- **主机**: AMD Lucienne APU (Ryzen 5 5500U), 14GB RAM
- **系统**: Debian 13 (Linux)
- **虚拟机磁盘**: `/home/a1/win11.qcow2` (Windows 11 不忘初心精简版)
- **外接盘**: `/dev/sda` (K5-60G, 60GB SSD, Windows 系统盘)

## 尝试 1：重建 Windows VM（QXL 显示）
- 使用 virt-manager 安装 win11.qcow2
- 磁盘用 virtio → 蓝屏（INACCESSIBLE_BOOT_DEVICE）
- 改为 SATA → 成功进桌面
- 精简版系统无法安装 QXL 显卡驱动（不包含 Win10/11 驱动安装功能）

## 尝试 2：VMware SVGA 显示
- 把显示从 QXL 改为 vmvga（Windows 自带 VMware SVGA 驱动）
- 可以显示，但依然没有 2D 加速

## 尝试 3：外接硬盘直通
- 外接盘 `/dev/sda` 连接到 VM
- 第一次成功启动，进入 Windows 桌面
- 尝试修改 CPU 配置（host-model）→ Windows 触发自动修复
- 重建 VM（virt-install 重新定义）→ 未加 snapshot 只读保护，外接盘被写入
- 后续重启仍然无法进入系统，自动修复死循环

## 根本问题
1. **笔记本单 GPU 无法直通**（IOMMU 分组、复位 bug、无第二 GPU）
2. **Windows 精简版不能安装标准驱动**（QXL/virtio 驱动安装器不可用）
3. **外接盘物理转虚拟**后硬件变更触发 Windows 自动修复，且 VM 配置变更加剧问题
4. **系统重启 libvirtd**时 service 卡死 zombie 进程，需硬重启

## 结论
- 不直通的情况下，Windows 虚拟机只能有 2D 基础显示（无硬件加速）
- 外接盘 Windows 即使第一次能进，硬件变更也会导致后续启动失败
- 任何 VM 配置变更（CPU 型号等）都会让 Windows 触发修复流程
