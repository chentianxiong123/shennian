# Claude(MiniClaude)折腾结论文档

> 结论版本:2026-08-02

## 三、构建策略:SSD 寿命敏感者的核心原则

> 核心原则:**可复用/持久缓存 → SSD;一次性构建垃圾 → 内存盘;SSD 只留最终成品。**

| 内容 | 位置 | 介质 | 性质 |
|---|---|---|---|
| bun 安装缓存 | `~/.bun/install/cache` | **SSD** | 可复用缓存,保留 |
| npm 缓存 | `~/.npm` (~12G) | **SDD** | 可复用缓存,保留 |
| 源码 + node_modules | `/tmp/minicl` | **内存盘(tmpfs)** | 一次性,重启清除,0SSD写 |
| 编译临时 | `TMPDIR=/tmp`、`BUN_INSTALL_CACHE_DIR=/tmp` | **内存盘** | 0SSD写 |
| **最终成品** | `~/.local/bin/claude` (176M) | **SDD** | **SSD 只放这一个结果** |

> 注:`/tmp` 已是 tmpfs(7.5G、内存盘),天然满足"编译放内存盘"。

### 构建步骤(已在 /tmp 完成)
```bash
cd /tmp
git clone --depth 1 https://github.com/txl16095/MiniClaude.git minicl
cd /tmp/minicl
export TMPDIR=/tmp
export BUN_INSTALL_CACHE_DIR=/tmp     # 临时写 RAM
bun install                            # 330 packages
bun run build --compile                 # 产物 ./dist/cli (内含所有依赖, --packages bundle)
# 落 SSD 成品
mkdir -p ~/.local/bin
cp dist/cli ~/.local/bin/claude
chmod +x ~/.local/bin/claude
claude --version   # -> 1.0.0 (Claude Code)
```
- 用 `--compile` 产出字节码、单文件、自包含 176M。
- `bin` 名:`miniclaude` 与 `mclaude`,最终**只保留 `claude`**。

> 命令命名:`claude`(符合官方习惯)。放大查看 `dist/cli` 在 `/tmp` 内存盘,源码可开平保存 `**claude`, 同时 `miniclaude` 已删。

### SSD 清理清单(已做)
已删:`~/.bun`(官方脚本残留)、`/tmp/bun-linux-x64.zip`、`/tmp/ccb`、`/tmp/minic`、`/tmp/minicl`(构建完源码)、`~/.local/bin/miniclaude` 副本。

## 四、Claude 的"那套配置和数据"长什么样

### 目录位置(源码 src/utils/envUtils.ts:7)
- 配置根:`~/.claude/`,可用环境变量 **`CLAUDE_CONFIG_DIR`** 改向(便于指向共享盘)。
- 另有顶级私有文件 `~/.claude.json`(machineID/userID/migration 骨架)。

### settings.json 家族(按优先级)
| 文件 | 位置 | 作用 |
|---|---|---|
| settings.json(用户级) | `~/.claude/settings.json` | 主配置 |
| settings.local.json(项目级) | `<项目>/.claude/settings.local.json` | 本地覆盖 |
| settings.json(项目级) | `<项目>/.claude/settings.json` | 项目级 |
| managed-settings.json | 政策/远程 | 强制策略 |

### settings.json 关键字段(接上游/cc-switch 用)
```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:15721",
    "ANTHROPIC_AUTH_TOKEN": "PROXY_MANAGED",
    "ANTHROPIC_MODEL": "deepseek-v4-pro[1m]",
    "API_TIMEOUT_MS": "3000000",
    "DISABLE_TELEMETRY": "1",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "model": "deepseek-v4-pro[1m]",
  "defaultModels": { "sonnet": "deepseek-v4-flash", "haiku": "deepseek-v4-flash", "opus": "deepseek-v4-pro[1m]" },
  "permissions": { "defaultMode": "default" },
  "mcpServers": { "chrome-devtools": { "command": "npx", "args": ["-y", "chrome-devtools-mcp@latest"] } },
  "language": "zh", "theme": "dark"
}
```
- `env` 中的 `ANTHROPIC_BASE_URL` / `AUTH_TOKEN` / `MODEL` 是接 cc-switch 网关的关键。
- MiniClaude 扩展了 `providers` 多 Provider 热切换(deepseek/kiro)。
- 官方 schema:`https://json.schemastore.org/claude-code-settings.json`

### 会话数据(cc-switch 接管源)
- 每次对话写入 `~/.claude/projects/<项目编码>/<sessionId>.jsonl`(源码 `sessionStorage.ts:199,204`)。
