# WinSxS 是系统组件库，绝对不能删

WinSxS (Windows Side-by-Side) 是 Windows 的系统组件存储库。

里面存着所有系统组件的**原始文件副本**，包括：
- 内核文件
- DLL 动态链接库
- 系统关键二进制

**删掉 WinSxS 的后果：**
- 开机黑屏，只有鼠标指针能移动
- 任务管理器打不开（Ctrl+Alt+Del 无效）
- 任何系统功能都无法使用
- 无法恢复，只能重装系统

看似 WinSxS 占空间很大（几 GB 到十几 GB），那是因为系统用硬链接让它看起来大，
实际占用远没显示的大。**Windows 自带的「磁盘清理」工具可以安全压缩 WinSxS，
但绝不要手动删除 WinSxS 目录。**

正确清理方式：
```
开始菜单 → 磁盘清理 → 清理系统文件
```
