# Windows 11「建议操作」——我用过最反人类的功能

## 这是什么

Windows 11 22H2 加入了「建议操作」(Suggested Actions)。当你复制一个**电话号码、日期、时间、快递单号**时，光标旁边会浮出一个微小的图标，提示你可以「用 Teams 拨打这个号码」或「在日历中添加这个日期」。

听起来好像很智能，实际体验是灾难级的。

## 有多傻逼

1. **毫无征兆地卡 UI**。复制内容后按 Alt+Tab 切换窗口，那个小图标卡在渲染队列里，导致界面出现一个残留的**下划线**或**半透明方块**，卡住几秒到十几秒。切一次卡一次。

2. **永远用不上**。Windows 在中国——谁用 Teams？谁用系统日历？谁需要 Windows 提醒你「这是一个日期」？我已经是个成年人了，我知道电话号码怎么用。

3. **关掉它比打开它难**。这个功能默认开启，关闭入口不在右键菜单里、不在通知栏里、不在任务栏设置里。藏在一级路径：

   ```
   设置 → 系统 → 剪贴板 → 建议操作 → 关
   ```

   正常人根本找不到。更离谱的是有些版本这个开关写死了直接不显示，必须改注册表：

   ```
   HKCU\Software\Microsoft\Windows\CurrentVersion\SuggestedActions\Enabled = 0
   ```

4. **性能开销不配它的存在价值**。一个需要在每次复制操作后实时分析剪贴板文本、识别实体、预计算操作选项、渲染 UI 动画的后台服务。就为了给一个 99% 的人关掉的功能供能。

## 微软在想什么

「建议操作」是典型的大公司「为了做而做」的功能。产品经理的 OKR 里有一条「提升剪贴板智能化」，于是不管用户要不要，先发了再说。没有人在 Windows 的日常使用场景下，会因为剪贴板多了一个图标而感到生产力提升。只会感到 Windows 又变卡了。

## 结论

功能是好功能——如果你是微软内部的 PM 用来写季度总结的话。

用户的话，关了就行。
