# 海思 HI3798MV100 盒子调优记录

## 环境
- 芯片: HI3798MV100 (hi3798mdmo1g)
- 系统: Ubuntu 20.04 LTS (海纳思 ecoo 第三方固件)
- 内存: 1GB
- 存储: 6.4GB eMMC
- IP: 192.168.31.82

## 串口连接
- 使用 FT232 USB-TTL 转串口
- 波特率: 115200
- 主机: `screen /dev/ttyUSB0 115200`

## ⚠️ 翻车教训: 不要用 dd 改 bootargs
直接 dd 写 `/dev/mmcblk0p2`(bootargs 分区) 极其危险:
- CRC 校验不对 → U-Boot 用默认值启动
- 参数写错(如 `mmz=ddr,0,0,0`) → 盒子变砖
- 备份存在盒子里 → 砖了也拿不到

**正确方法: 串口进 U-Boot(fastboot) 改环境变量**

## bootargs 调优 — 释放 mmz 内存

### 原始状态
- `mem=1G mmz=ddr,0,0,256M` — 解码器吃掉 256M
- 系统可用: ~723MB

### 优化: mmz 从 256M → 16M
在 fastboot 提示符执行:
```
setenv bootargs_1G mem=1G mmz=ddr,0,0,16M vmalloc=500M
saveenv
run bootcmd
```
**效果:** 系统可用从 723MB → ~960MB，省 240MB

### 其他模板(可选)
- 512M 内存: `bootargs_512M`
- 768M 内存: `bootargs_768M`
- 1G 内存(本机): `bootargs_1G`
- 2G 内存: `bootargs_2G`
- 3840M(仅限 4G 内存): `bootargs_3840M`

## 改 MAC 地址
```
setenv ethaddr AA:BB:CC:DD:EE:FF
saveenv
```

## 磁盘清理
- swapfile 513M — `swapoff /swapfile && rm -f /swapfile` (0 使用纯浪费)
- apt 缓存 — `apt clean`
- 日志 — `journalctl --vacuum-time=3d`
- 清理后从 1.7G → 1.1G 使用量
