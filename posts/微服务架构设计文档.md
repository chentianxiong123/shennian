## 第一章 系统概述

### 1.1 项目背景

随着互联网技术的快速发展和在线教育的普及，视频学习平台已成为高校学生和自学者获取知识的重要渠道。传统的视频学习平台存在互动性不足、内容检索困难、学习效率低下等问题。本项目旨在构建一个基于微服务架构的在线学习视频社区平台，整合视频播放、弹幕互动、智能摘要、内容搜索等功能，为用户提供沉浸式的学习体验。

### 1.2 系统目标

1. **高可用性**：通过微服务架构实现服务的独立部署和故障隔离
2. **可扩展性**：支持按需扩展高负载服务，提升系统承载能力
3. **可维护性**：服务边界清晰，便于独立开发和维护
4. **用户体验**：提供流畅的视频播放、实时弹幕互动体验

### 1.3 目标用户群体

| 用户类型 | 描述 | 主要需求 |
|---------|------|---------|
| 普通用户 | 高校学生、自学者 | 观看视频、发送弹幕、评论互动、内容搜索 |
| 内容创作者 | 教师、知识博主 | 上传视频、管理内容、查看数据统计 |
| 系统管理员 | 平台运营人员 | 用户管理、内容审核、系统监控 |

### 2.2 微服务拆分策略

根据业务领域和功能边界，系统拆分为以下微服务：

| 服务名称 | 服务标识 | 端口 | 核心职责 |
|---------|---------|------|---------|
| 用户服务 | user-service | 8081 | 用户注册、登录、权限管理、个人信息 |
| 视频服务 | video-service | 8082 | 视频上传、转码、播放、稿件管理 |
| 弹幕服务 | danmaku-service | 8083 | 弹幕发送、显示、管理 |
| 搜索服务 | search-service | 8084 | 视频搜索、热门搜索、搜索推荐 |
| 评论服务 | comment-service | 8085 | 评论发布、回复、点赞 |
| 互动服务 | interaction-service | 8086 | 点赞、投币、收藏、分享 |
| 消息服务 | message-service | 8087 | 私信、通知、系统消息 |
| AI服务 | ai-service | 8088 | 智能摘要、字幕识别 |

### 5.3 认证过滤器

```java
@Component
public class AuthGlobalFilter implements GlobalFilter, Ordered {
    
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String path = exchange.getRequest().getPath().value();
        
        if (isWhitePath(path)) {
            return chain.filter(exchange);
        }
        
        String token = exchange.getRequest().getHeaders().getFirst("Authorization");
        if (token == null || !JwtUtils.validateToken(token)) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
        
        Integer userId = JwtUtils.getUserIdFromToken(token);
        ServerHttpRequest request = exchange.getRequest().mutate()
            .header("X-User-Id", String.valueOf(userId))
            .build();
            
        return chain.filter(exchange.mutate().request(request).build());
    }
    
    @Override
    public int getOrder() {
        return -100;
    }
}
```

@Component
public class VideoTranscodeConsumer {
    
    @Autowired
    private FFmpegService ffmpegService;
    
    @Autowired
    private VideoService videoService;
    
    @RabbitListener(queues = VIDEO_TRANSCODE_QUEUE)
    public void handleTranscode(VideoTranscodeMessage message) {
        try {
            TranscodeResult result = ffmpegService.transcode(
                message.getSourcePath(),
                Arrays.asList("1080p", "720p", "480p")
            );
            
            videoService.updateVideoUrls(
                message.getVideoId(),
                result.getPlayUrls()
            );
            
            videoService.updateProcessStatus(
                message.getVideoId(),
                ProcessStatus.COMPLETED
            );
        } catch (Exception e) {
            videoService.updateProcessStatus(
                message.getVideoId(),
                ProcessStatus.FAILED
            );
        }
    }
}
