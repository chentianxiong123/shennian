## 未完成的迁移

### 1. NVM + Node.js（用户说先不管）
- 当前位置：D:\Program Files (x86)\nvm
- Node 版本：v22.22.2
- 迁移方法：Move-Item 到 D:\devtools\nvm，更新 NVM_SYMLINK 和 PATH

### 2. Docker Desktop（已部分迁移，需整合到 D:\devtools）
- 配置文件：%APPDATA%\Docker\settings-store.json
- CustomWslDistroDir 已指向：D:\DockerData\DockerDesktopWSL
- 数据大小：~53 GB
- 迁移方法：
  1. 关闭 Docker Desktop
  2. Settings → Resources → Advanced → Disk image location 改到 D:\devtools\DockerData\DockerDesktopWSL
  3. 删除 C:\Users\a1\AppData\Local\Docker\wsl
  4. 验证：docker run --rm hello-world

### 3. WSL Ubuntu（需整合到 D:\devtools）
- 当前位置：D:\wsl\ubuntu
- 已导出备份：D:\devtools\wsl\ubuntu.tar (1.49 GB)
- 迁移方法：
  1. wsl --shutdown
  2. wsl --unregister Ubuntu
  3. wsl --import Ubuntu D:\devtools\wsl\ubuntu D:\devtools\wsl\ubuntu.tar
  4. 删除 D:\wsl 和 D:\DockerData 旧目录
