# 海思 hi3798mv100 机顶盒深度清理记录

> 设备: hi3798mv100 / 4核 ARMv7 / 723MB RAM / 6.4GB eMMC  
> 系统: Ubuntu 20.04.6 LTS (Focal Fossa) / Kernel 4.4.35  
> 日期: 2026-06-30

---

## 清理前状态

一台跑着 Ubuntu 的机顶盒，被当作小型服务器使用，堆了各种服务。开机后内存占用 329MB/723MB，磁盘 3.1GB/6.4GB。

| 服务/进程 | 用途 | 内存占用 |
|---|---|---|
| **青龙面板 (Node.js × 3)** | 定时任务面板 | ~180MB |
| **PM2** | Node 进程管理器 | 46MB |
| **LinkEase / 可道云** | 私有云同步 | 44MB |
| **dockerd + containerd** | Docker 引擎 | ~45MB |
| **Portainer** | Docker 管理 UI | 17MB |
| **Alist** | 文件列表服务 | 20MB |
| **Filebrowser** | 文件管理器 | 16MB |
| **Samba (smbd + nmbd)** | Windows 文件共享 | ~15MB |
| **NFS (mountd + idmapd + blkmap)** | 网络文件系统 | ~30MB |
| **Gunicorn** (青龙后端) | Python WSGI | ~20MB |
| **ModemManager** | 猫管理(无用) | ~10MB |
| **smartmontools** | 硬盘 SMART(无用) | ~5MB |
| **transmission-daemon** | BT 下载器 | 6.5MB |
| **vlmcsd** | KMS 激活服务器 | 少量 |
| **vsftpd** | FTP 服务器 | 少量 |

| **rsyslog** | 系统日志 | 少量 |

**总计: ~25 个服务进程**，内存占用 ~329MB，Swap 使用 17MB。

---

## 清理过程

### 第一阶段: 无争议垃圾

| 操作 | 回收空间 |
|---|---|
| `apt remove modemmanager` | 2.9MB 磁盘 |
| `apt remove smartmontools` | 1.5MB 磁盘 |
| `apt remove unattended-upgrades` | 451KB 磁盘 |
| `apt remove nfs-kernel-server` | 288KB 磁盘 |
| `kill + rm wsdd` | 少量 |
| `apt autoremove` (依赖清理) | 3.3MB 磁盘 |

### 第二阶段: 用户确认删除

| 操作 | 回收内存 | 回收磁盘 |
|---|---|---|
| 停用并删除 LinkEase | 44MB | - |
| 停用并删除 Filebrowser | 16MB | - |
| 停用并删除 Aria2c | 少量 | - |
| `apt remove samba + autoremove` | ~15MB | **80MB 磁盘** |

### 第三阶段: Docker 容器清理

| 操作 | 回收内存 |
|---|---|
| `docker rm Portainer + rmi` | 17MB |
| `docker rm ql + rmi` | **~180MB** (青龙3进程) |
| `docker system prune` | 清理网络/缓存 |

### 第四阶段: 停用 Docker

| 操作 | 回收内存 |
|---|---|
| `systemctl disable --now docker` | 45MB |
| `systemctl disable --now containerd` | - |

### 第五阶段: 顽固服务

| 操作 | 回收内存 |
|---|---|
| 停用并删除 vlmcsd (KMS) | 少量 |
| 停用并删除 ttyd (Web终端) | 少量 |
| `apt remove vsftpd` | 少量 |
| `apt remove rpcbind + nfs-common` | 2.5MB |
| `apt remove transmission-daemon + 依赖` | 6.5MB |
| `apt autoremove` (libtirpc等) | 731KB 磁盘 |

### 第六阶段: Nginx 站点清理

| 操作 |
|---|
| 备份 `/var/www/` → `/root/backup-www/` |
| 删除 port 80 主面板 (`/var/www/html/` + 域名绑定) |
| 删除 port 6008 cronweb (`apt remove cronweb-histb`) |
| 删除 port 8081 WebDAV (`/home/ubuntu/webdav/`) |
| 移除全部 nginx 站点配置，重载生效 |
