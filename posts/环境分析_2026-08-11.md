## 二、Waydroid 文档分析

### 正确的判断

1. **"与宿主机共享内存池"** — 完全正确。LXC cgroup 共享内核，不预分配物理内存，实测容器闲置 ~21M。
2. **"ARM-only 闭源应用需翻译层"** — 核心限制。微信、大部分手游、抖音等纯 ARM 应用跑不了，这是 x86_64 Waydroid 的天花板。
3. **binder 模块用 anbox 命名** — 对的，Waydroid init 脚本认这个设备名。

### 技术亮点

- **SourceForge 绕过 UA 拦截**：Python urllib 拿带时间戳签名的真实 URL → aria2 挂代理下载，9.3MB/s。标准做法。
- **ro.adb.secure=0 免 RSA**：省了命令行授权的麻烦，调试链完整。
- **setsid 防超时杀**：bash 命令超时导致容器 FROZEN 的坑，用 `setsid` + 轮询脚本解决。

### 未解决问题

- **Flutter debug 构件缺失**：华为云镜像缺 `io.flutter` debug 构件，`flutter run` 失败。release 构建 OK。

## 三、Flutter 文档分析

### 正确的判断

1. **镜像分层策略**：SDK 下载用腾讯、pub 依赖用清华、引擎构件用华为云。各取所长，标准操作。
2. **Gradle 9 的 FAIL_ON_PROJECT_REPOS**：新版 Gradle 禁止项目级仓库声明，统一到 settings 管理。这个坑记录得清楚。
3. **升级后必须清缓存**：`.gradle .dart_tool build` 三个目录，否则新旧版本混用必崩。

### 未解决问题

- **同上**：debug 构件缺失，与 Waydroid 文档重复记录。

## 四、交叉分析

### 4.1 共性问题：debug 构建

两份文档都记录同一个未解决问题——华为云镜像缺 debug 构件。影响：

- 只能用 `flutter build apk --release` 出包
- `flutter run -d waydroid` 调试走不通
- 需要挂代理走 `storage.googleapis.com` 补齐，或者找完整镜像

**优先级：中。** 如果你主要用 release 调试（装包后看效果），影响不大。如果需要热重载开发，必须先解决。

### 4.2 架构一致性：x86_64 贯穿

| 层 | 架构 |
|----|------|
| 主机 Ryzen5-5500U | x86_64 |
| Waydroid Android 13 | x86_64 |
| Flutter 目标 ABI | x86_64 |
| 未来 E5-2650L V4 服务器 | x86_64 |

**全部 x86_64，架构无切换。** 好处：Flutter APK 可以一次性构建，Waydroid 直接跑。坏消息：ARM-only 应用（微信、抖音、大部分手游）这条路永远走不通。

### 4.3 未来 E5 服务器的价值定位

基于当前部署，新服务器的角色应该是：

| 用途 | 是否匹配 |
|------|---------|
| **CI/构建服务器** | ✅ Flutter 自动构建、APK 输出 |
| **多环境隔离** | ✅ LXC 跑多个 Android 版本做兼容测试 |
| **Waydroid on PVE VM** | ⚠️ PVE VM 里跑 Waydroid 可行，但不如本机快 |
| **NAS 存储** | ✅ 存 Flutter 项目、APK、镜像 |
| **macOS VM** | ✅ 需要 GPU 直通（你的 RX580） |
| **替代本机 Waydroid** | ❌ 没必要，本机调试延迟最低 |

**结论：新服务器做 CI + NAS + macOS VM，本机继续跑 Waydroid 做日常调试。**

### 4.4 当前最大的两个阻塞

1. **debug 构件缺失** → 阻塞 Flutter 日常热重载调试
2. **ARM 应用不兼容** → 微信/抖音等常用软件装不了

## 五、建议

### 优先级 高

- **解决 debug 构件**：挂代理或配置多镜像源，让 `flutter run` 能工作
- **E5 服务器规划**：确定后把 Flutter 构建链搬过去做 CI

### 优先级 中

- **ARM 应用替代方案**：如果确实需要微信/抖音，考虑 Waydroid + qemu-user 翻译层（性能差，仅能用），或者接受这个限制
- **.wine 清理**：装了就放着不用，不如删了省空间

### 优先级 低

- **LXC 多版本 Android**：未来 E5 上跑不同 API 版本的 Android 做兼容测试，等服务器到手再说
